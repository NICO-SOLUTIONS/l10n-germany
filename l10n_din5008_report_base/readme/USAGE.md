To configure the DIN 5008 report layout:
* Make sure the correct company is selected. If necessary, switch to the company whose DIN 5008 report layout you want to configure.
* Go to **Settings > General Settings** and select **Configure Document Layout** in the Company section.
* Under **Document Layout**, select the **DIN 5008** report layout.
* Click **Configure DIN 5008 parameters** to open the configuration dialog.
* Adjust the available DIN 5008 settings in the respective sections as required, then click **Apply** to save your changes.
* Generate a report using the DIN 5008 report layout to verify the result.

**Note:** The configured settings apply only to reports that use the DIN 5008 external report layout.

**The wizard preview and the generated printout may differ slightly. Always use the generated report as the reference for the final result.**
